# KLEANFW 0.1.0

First release of KLEANFW, a custom firmware for the **Quansheng UV-K1 /
UV-K5 V3 (PY32F071 + BK4829 only)**. It is a modified version of
[GOGUFW 3.6.2](https://github.com/Gogu-Qs/GOGUFW-UV-K1-Messenger) by Gogu-Qs
(F4HWN 6.3.0 base) and an independent project, not affiliated with or
endorsed by Gogu-Qs, F4HWN or Quansheng.

## Highlights

- **HOP voice scrambler**: the inversion carrier changes every 500 ms
  following the shared CryKey, with a seed burst at each PTT and a resync
  every 8 s. FM only. Not encryption.
- **CryKey**: with a passphrase set in MENU → Msg → CryKey (or CHIRP),
  Messenger text is sent XTEA-CTR encrypted.
- **Spectrum rework**: MR mode sweeps the active scan list, key 6 bandwidth
  persists, PTT×2 opens the matching MR channel, backlight follows BLTime.
- **Less SPI flash wear**: deferred sector erases, Messenger IDs reserved in
  blocks of 64, mute no longer writes the calibration sector.
- **Fixes**: USB serial commands no longer freeze the radio (UV Studio,
  CHIRP over USB), Spectrum hangs and filters, UI overlaps.
- F Lock: BRASIL (default), DISABLE ALL, UNLOCK ALL. F4HWN menu categories.

Full list: [CHANGELOG.md](https://github.com/AislanJefferson/KLEANFW/blob/main/CHANGELOG.md).
Manual (Portuguese): [MANUAL.md](https://github.com/AislanJefferson/KLEANFW/blob/main/MANUAL.md).

## Files

| --- | --- |
| `KLEANFW-v0.1.0.bin` | Firmware image (normal flashing) |
| `KLEANFW-v0.1.0-multiboot.bin` | Same image, multiboot file name |
| `KLEANFW_0.1.0_chirp_module.py` | Matching CHIRP module (GPL-2.0-or-later) |

| `Apps.zip` | Every overlay app built from this source |

Image: 120,772 / 120,832 bytes including the 920-byte multiboot load image.

## Before you flash

- Back up the radio and its calibration with CHIRP and keep a DFU recovery
  image.
- First boot after updating: the version reset clears KEY_LOCK, MENU_LOCK,
  SET_KEY and SET_INV and turns `SetRxG` back ON.
- Use only the KLEANFW 0.1.0 CHIRP module (model **UV-K1 / UV-K5 V3 KLEANFW**).
- Install both FM apps and Search.app with UV Studio (Apps page).
